Usage: k3s create [OPTIONS] NAME

  Create a new k3s cluster

Options:
  --control-plane-count INTEGER   The number of control plane nodes
  --worker-count INTEGER          The number of workers
  --metal-address-count INTEGER   The number of floating addresses to route into
                                  the virtual network for metallb to manage.
                                  Ignored if --no-metallb is passed.
  --namespace TEXT                If you are an admin, you can create this
                                  cluster in a different namespace.
  --network TEXT                  Specify a network here to add these nodes to a
                                  pre-existing network. Otherwise one will be
                                  created for this cluster.
  --refresh-version-cache / --no-refresh-version-cache
                                  Force a refresh of the k3s version cache.
  --release-channel TEXT          Select a k3s release channel. Common choices
                                  include stable, latest, and specific versions
                                  pre-pended with a v such as "v1.26".
  --sshkey PATH                   An optional ssh public key to place onto
                                  instances.
  --metallb / --no-metallb        Install metallb for load balancer addresses.
                                  --metal-address-count is ignored when this is
                                  off.
  --longhorn / --no-longhorn      Install longhorn for persistent storage.
  --kubeconfig / --no-kubeconfig  Add the new cluster to your local
                                  ~/.kube/config, merging it into any existing
                                  configuration. Cluster credentials remain
                                  available from 'sf-client k3s getconfig'
                                  either way.
  --help                          Show this message and exit.
