Usage: k3s delete [OPTIONS] NAME

  Destroy a k3s cluster

Options:
  --namespace TEXT                If you are an admin, you can alter clusters in
                                  a different namespace.
  --kubeconfig / --no-kubeconfig  Remove the deleted cluster from your local
                                  ~/.kube/config. This is the counterpart of the
                                  same flag on create.
  --help                          Show this message and exit.
